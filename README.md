# Projeto de Estágio — Engenharia de Software

Repositório para organizar meu estágio obrigatório, em um escritório de advocacia, para o curso de Engenharia de Software da UTFPR — Campus Cornélio Procópio.

## Objetivos iniciais

- Registrar informações, responsabilidades e documentos do estágio.
- Planejar atividades técnicas compatíveis com Engenharia de Software.
- Acompanhar entregas, avaliações e relatórios.
- Evoluir, caso necessário, para um sistema de apoio à gestão do estágio.

## Estrutura

- [`docs/regras-estagio.md`](docs/regras-estagio.md): regras e premissas atualmente consideradas.
- [`docs/plano-de-atividades.md`](docs/plano-de-atividades.md): proposta inicial de plano de atividades.
- [`docs/checklist-formalizacao.md`](docs/checklist-formalizacao.md): checklist de formalização e acompanhamento.
- [`.github/copilot-instructions.md`](.github/copilot-instructions.md): princípios técnicos para qualquer implementação neste repositório.
- [`ATAS/ATA-001-reuniao-inicial.pdf`](ATAS/ATA-001-reuniao-inicial.pdf): registro da reunião inicial e das perguntas pendentes.
- [`AGENTS.md`](AGENTS.md): persona persistente do estagiário de Engenharia de Software.

## Próximos passos

1. Confirmar com a UTFPR a modalidade do estágio, a matriz curricular aplicável e os formulários oficiais.
2. Identificar o professor orientador/PRAE e o supervisor da concedente.
3. Definir o produto ou projeto técnico que será desenvolvido.
4. Aprovar o Plano de Atividades antes do início das atividades.

> Este repositório é um instrumento de organização. A validação oficial deve ser feita com a UTFPR, especialmente DERAC/COEST, coordenação do curso e professor responsável pelo estágio.
