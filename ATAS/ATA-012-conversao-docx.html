ATA 012 — Primeira conversão Markdown para DOCX

Data: 24/08/2026
Projeto: Plataforma local de gestão jurídica e automação assistida
Referência: ATA 011

Ambiente

Python 3.12.10 e a biblioteca python-docx foram confirmados. Pandoc não está instalado.

Entrega

Foi criado scripts/md_to_docx.py, que recebe Markdown, usa o modelo timbrado, preserva o cabeçalho, adiciona o conteúdo e salva novo DOCX sem alterar o modelo.

Limitações

Ainda não há PDF, integração com o site ou aprovação. O DOCX deve ser revisado visualmente.

Próximo passo

Testar com minuta fictícia, revisar o timbre e implementar aprovação e PDF.

Anexo técnico — lógica de programação

Trecho de scripts/md_to_docx.py com a função central da conversão (explicação completa em docs/logica-de-programacao.md):

def convert(source: Path, template: Path, destination: Path) -> None:
    document = Document(template)
    document.add_page_break()
    for line in source.read_text(encoding="utf-8-sig").splitlines():
        add_markdown_line(document, line)
    for paragraph in document.paragraphs:
        for run in paragraph.runs:
            if not run.font.name:
                run.font.name = "Arial"
            if not run.font.size:
                run.font.size = Pt(11)
    destination.parent.mkdir(parents=True, exist_ok=True)
    document.save(destination)

A função abre o modelo timbrado como base, preservando cabeçalho e logotipo, e percorre o Markdown linha por linha, delegando a "add_markdown_line()" o reconhecimento de títulos, seções, negrito e separadores.

Registro de acompanhamento. Não substitui documentos oficiais da UTFPR nem instrumentos jurídicos.
