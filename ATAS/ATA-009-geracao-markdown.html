ATA 009 — Geração real do Markdown

Data: 03/08/2026
Projeto: Plataforma local de gestão jurídica e automação assistida
Referência: ATA 008

Entrega

O protótipo passou a gerar uma minuta Markdown real a partir do formulário de manifestação simples, com download local do arquivo.

Funcionamento

  • Valida campos obrigatórios.
  • Compõe Markdown com cliente, processo, finalidade, fatos e pedido.
  • Inclui data/hora.
  • Indica revisão obrigatória do advogado.

Limitações

Ainda não há banco, login real, salvamento permanente, conversão DOCX/PDF ou IA. Usar apenas dados fictícios.

Próximo passo

Implementar conversão para DOCX usando o modelo timbrado.

Anexo técnico — lógica de programação

Trecho de prototype/index.html responsável pela geração descrita acima (explicação completa em docs/logica-de-programacao.md):

function values(){
  const d=new FormData(form);
  return {
    cliente:String(d.get('cliente')||'').trim(),
    processo:String(d.get('processo')||'').trim(),
    finalidade:String(d.get('finalidade')||'').trim(),
    fatos:String(d.get('fatos')||'').trim(),
    pedido:String(d.get('pedido')||'').trim()
  };
}
function makeMarkdown(v){
  return `# Manifestação simples

**Cliente/parte representada:** ${v.cliente}
**Processo:** ${v.processo}

## Finalidade

${v.finalidade}

## Fatos e informações

${v.fatos}

## Pedido ou providência

${v.pedido}
`;
}
function valid(v){ return Object.values(v).every(Boolean); }

"values()" lê o formulário com FormData; "valid()" confirma que nenhum campo obrigatório ficou vazio; "makeMarkdown()" monta o texto final no formato Markdown descrito acima.
