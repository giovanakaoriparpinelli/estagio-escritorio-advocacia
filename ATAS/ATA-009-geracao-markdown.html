ATA 009 — Geração real do Markdown

Data: 14/09/2026
Projeto: Plataforma local de gestão jurídica e automação assistida
Referência: ATA 008

Entrega

O protótipo passou a gerar uma minuta Markdown real a partir do formulário de manifestação simples, com download local do arquivo.

Funcionamento

  • Valida campos obrigatórios.
  • Compõe Markdown com cliente, processo, finalidade, fatos e pedido.
  • Inclui data/hora.
  • Indica revisão obrigatória do advogado.

Limitações

Ainda não há banco, login real, salvamento permanente, conversão DOCX/PDF ou IA. Usar apenas dados fictícios.

Próximo passo

Implementar conversão para DOCX usando o modelo timbrado.

Registro de acompanhamento. Não substitui documentos oficiais da UTFPR nem instrumentos jurídicos.
