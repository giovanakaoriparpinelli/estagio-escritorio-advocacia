# Requisitos do protótipo — Manifestação simples

## Formulário inicial

1. Cliente ou parte representada — obrigatório.
2. Número do processo — obrigatório.
3. Juízo/vara — opcional no primeiro protótipo.
4. Finalidade da manifestação — obrigatório.
5. Fatos e informações — obrigatório.
6. Pedido/providência — obrigatório.
7. Documentos mencionados — opcional.
8. Observações internas — opcional e não destinadas ao documento final.

## Saída esperada

O sistema deverá gerar uma minuta Markdown com identificação, corpo da manifestação e pedido, mantendo campos claramente identificáveis para revisão do advogado.

## Critérios de aceite

- O advogado consegue preencher o formulário com dados fictícios.
- O sistema valida campos obrigatórios.
- O rascunho gerado pode ser visualizado e salvo.
- O sistema deixa claro que a minuta aguarda revisão profissional.
- O layout é coerente com o modelo timbrado.
